# Enterprise Data Architecture – NexStar Finance

## Overview
This project presents an enterprise data architecture and data management strategy for NexStar Finance, a hypothetical global fintech organization operating across the United States, Latin America, and Africa.

The objective was to assess fragmented data systems and design a scalable, governed architecture capable of supporting analytics, regulatory compliance, and executive decision-making.

---

## The Problem
NexStar Finance’s customer, transaction, and vendor data existed across siloed systems, limiting real-time insights, increasing fraud risk, and creating compliance exposure across multiple regions.

Leadership lacked a unified data model to support enterprise analytics and operational reporting.

---

## What I Built
- A conceptual enterprise data architecture aligned with industry best practices  
- A normalized relational data model supporting customer, transaction, and vendor entities  
- Governance and data quality considerations for global operations  
- SQL table definitions demonstrating implementable schema design  

---

## Tools & Methods
- SQL (relational modeling and schema design)
- Entity-relationship modeling
- Enterprise data management concepts
- Decision-support architecture design
